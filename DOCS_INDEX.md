## 🆘 Common Questions

**Q: How do I run the app locally?**  
A: `npm install` then `npm run dev` then open http://localhost:5175

**Q: How do I log in without Supabase?**  
A: Use ANY email/password - demo auth accepts anything

**Q: What's the default user after login?**  
A: "Sakthi Renganathan" (demo nurse role)

**Q: Can I deploy now?**  
A: YES! Run `npm run build` then deploy dist/ folder

**Q: Do I need Supabase to deploy?**  
A: Optional - app works with mock data, but needs it for production persistence

**Q: How do I connect real Supabase?**  
A: Set env vars in deployment platform and restart

**Q: What if I get errors?**  
A: See "Troubleshooting" section in [QUICK_START.md](./QUICK_START.md)
