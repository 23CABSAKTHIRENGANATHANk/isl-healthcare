# ISL Setu — Indian Sign Language for Healthcare

An accessible Indian Sign Language (ISL) healthcare learning, practice, and communication platform.

## Quick Start (Run Locally)

### Option 1: Run from Root Directory
```bash
# Install dependencies in the app directory
npm install --prefix isl-healthcare-connect-main

# Start development server
npm run dev
```

### Option 2: Run from `isl-healthcare-connect-main` Directory
```bash
cd isl-healthcare-connect-main

# Install dependencies
npm install

# Start development server
npm run dev
```

Once the dev server starts, open [http://localhost:3000](http://localhost:3000) or the port displayed in your terminal.

## Available Scripts

- `npm run dev`: Start local development server
- `npm run build`: Build production bundle
- `npm run preview`: Preview production build
- `npm run lint`: Run ESLint checks
